# One Tiny Delivery

One Tiny Delivery is a small Unity delivery game set on a big island with a forest, fields, valleys, and mountains. Drive the three wheeled truck, pick up packages, and complete deliveries across the map.
Explore the vast map and talk to the people along the way to hear their stories!

## Controls

- WASD or arrow keys: drive and steer
- Space: handbrake
- Mouse: move the camera
- Enter: continue or enter dialogue
- R: restart the current delivery
- Escape: pause

## Running the unity project 

(THIS PROJECT TAKES UP A LARGE AMOUNT OF SPACE, if you just want to play the game, go to https://lamp-dude.itch.io/one-tiny-delivery) 

1. Open `One Tiny Delivery1` in Unity Hub.
2. Use Unity version `6000.3.16f1`.
3. Open the project and press Play.

The main gameplay scene uses streamed terrain scenes under `Assets/Scenes/Terrain`.

## Main folders

- `Assets/Scripts` - game code
- `Assets/Scenes` - menu, terrain, and finale scenes
- `Assets/Art` - player vehicle art and related assets
- `Assets/Resources` - intro resources
